Models Used

MediaPipe FaceLandmarker 01 — Detect

Google's pretrained face-mesh model. Detects a face and extracts 478 landmark points (eyes, eyebrows, nose, mouth, jawline); head pose (yaw/pitch/roll) is then computed from those points with OpenCV's solvePnP.

InsightFace — buffalo_l & inswapper_128 02 — Swap

buffalo_l detects the face and extracts an identity embedding; inswapper_128 places that identity onto the target photo's face realistically. The similarity score is the cosine similarity between the source and result face's embedding vectors.

Wav2Lip 03 — Lip Sync

A model trained for audio-visual sync that regenerates the mouth region in each video frame to match the given audio's mel-spectrogram (Rudrabha/Wav2Lip, GAN variant). Runs in its own virtual environment, isolated from this project's main codebase.

No model in this project was trained from scratch — every one runs on ready-made, pretrained weights; this project's own code only provides the interface and data flow connecting them.

The face-swap and lip-sync outputs this system produces are synthetic and each one carries a visible "AI GENERATED" watermark.
